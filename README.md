# 竹岡 修一（たっけん）

日本電子専門学校で学ぶ、モバイルアプリ開発を志望する学生です。
iOS / Swift（SwiftUI）を中心に、チーム制作のゲーム開発と、実際に使われているツールの開発・運用に取り組んでいます。
開発では生成AIの支援も活用しており、現在は担当した部分を中心に、コードの仕組みへの理解を深めている段階です。

## 主な作品

### [What's gathered? Run! ― ワギャラン](https://github.com/26cm0120-alt/What-s-gathered-Run-)
迷宮探索 × カードしりとりのiOSゲーム（チーム制作・開発中）。
担当は、SwiftUIを使った画面づくり（タイトル〜探索〜結果表示）と、迷宮生成の仕組みです。
画面写真、遊び方、担当と工夫はREADMEにまとめています。

### [マシロのトリックパンプキン祭り](https://github.com/26cm0120-alt/mashiro-trick-pumpkin)
Unity / C# で制作した、強制横スクロールの2Dアクションゲーム。
初めてのゲーム制作で、高校の文化祭への出展を目標に約3か月で制作しました。
PV、Windows版ダウンロード、主要コードの読みどころをREADMEにまとめています。

### [Discord 読み上げBot](https://github.com/26cm0120-alt/Discord-Bot)
Node.js を使い、生成AIの支援も受けながら開発し、実サーバーで使っている1サーバー専用の読み上げBot。
VOICEVOX / GPT-SoVITS連携、読み上げ遅延の計測、Docker対応など、運用しながら改善を続けています。

### [Roxycall コミュニティポータル](https://github.com/26cm0120-alt/Roxycall)
ゲームコミュニティの公式ポータルサイト。
GitHub ActionsによるDiscordメンバーの自動同期と、Cloudflare Workers / D1 / R2を使ったログイン付きプロフィール編集の仕組みを使っています（設定や仕組みは学習しながら運用しています）。

## 技術について（経験と学習状況）

開発では生成AIの支援も活用しています。そのため、作品で使用した技術でも、すべてを自力で実装・説明できる段階ではないものがあります。
現在は、担当した部分を中心にコードを読んで仕組みを理解することと、デバッグ力をつけることに取り組んでいます。

| 区分 | 内容 |
| --- | --- |
| 学習中の中心分野 | Swift / SwiftUI（授業とチーム制作で学習中。SwiftUIの画面づくりを担当した経験があります） |
| 作品で使用した経験がある | Unity / C#（ゲーム制作）、Node.js・JavaScript（Discord Bot）、HTML / CSS（ポータルサイト）、Firebase（Firestore） |
| 制作・運用の中で触れた | Cloudflare Workers / D1 / R2、Docker、GitHub Actions（AIの支援を受けながら設定・運用した経験があります。仕組みは学習中です） |
| ツール | Git / GitHub、Xcode（どちらも基本的な使い方を学習中です） |
| 今取り組んでいる課題 | コードの仕組みを自分の言葉で説明できるようにすること、エラーや不具合を自分で切り分けて直すこと |
